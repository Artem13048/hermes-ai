============================================================
ИНСТРУКЦИЯ ПО ЗАПОЛНЕНИЮ JSON-ФАЙЛА ДЛЯ ИМПОРТА МЕСТ
============================================================

Формат файла: JSON (UTF-8).
Имя файла: любое, главное — расширение .json
Куда отправить: в чат с ботом Hermes.AI (просто прикрепи файл).

------------------------------------------------------------
СТРУКТУРА ФАЙЛА
------------------------------------------------------------

Файл состоит из ДВУХ блоков:

  1. "cities"  — список городов
  2. "places"  — список мест

Блок "categories" ОТСУТСТВУЕТ — категории уже зафиксированы
в системе, их ID указаны ниже. Менять их НЕЛЬЗЯ.

------------------------------------------------------------
БЛОК "cities" — ГОРОДА
------------------------------------------------------------

Формат одного города:

{
  "id": 1,
  "name": "Название города",
  "region": "Регион",
  "country": "Россия",
  "latitude": 0.0,
  "longitude": 0.0
}

Пояснения по полям:

  id         — ЛОКАЛЬНЫЙ номер города ВНУТРИ файла (1, 2, 3, ...).
               НЕ совпадает с id в базе данных. Нужен только для
               связи с полем "city_id" в блоке "places".

  name       — название города.
  region     — регион.
  country    — страна (по умолчанию "Россия").
  latitude   — широта центра города.
  longitude  — долгота центра города.

Если город уже есть в базе — он НЕ будет создан повторно.
Поиск идёт по паре (name, region).

------------------------------------------------------------
БЛОК "places" — МЕСТА
------------------------------------------------------------

Формат одного места:

{
  "city_id": 1,
  "category_id": 1,
  "name": "Название места",
  "address": "Конкретный адрес",
  "description": "Краткое описание",
  "long_description": null,
  "price": "0",
  "ticket_url": null,
  "source_url": null,
  "photo_url": null,
  "latitude": 55.790000,
  "longitude": 49.100000,
  "rating": null,
  "is_active": true,
  "opening_hours": "10:00-20:00",
  "benefits": null
}

Пояснения по полям:

  city_id       — ОБЯЗАТЕЛЬНО. Локальный id города из блока "cities".
  category_id   — ОБЯЗАТЕЛЬНО. ID существующей категории (1–6).
  name          — ОБЯЗАТЕЛЬНО. Название места.
  address       — ОБЯЗАТЕЛЬНО. Конкретный адрес места.
  description   — Краткое описание.
  long_description — Расширенное описание или null.

  price         — Стоимость посещения в виде строки.
                  Бесплатно: "0".
                  Платно: например "500" или "от 300".

  ticket_url    — Ссылка на покупку билета или null.
  source_url    — Ссылка на источник информации или null.
  photo_url     — Прямая ссылка на фотографию или null.
                  Предпочтительно .jpg, .jpeg или .png.

  latitude      — ОБЯЗАТЕЛЬНО. Точные координаты места.
  longitude     — ОБЯЗАТЕЛЬНО. Точные координаты места.
  rating        — Рейтинг от 0 до 5 или null.
  is_active     — true / false.

  opening_hours — ВАЖНО. Используется при построении маршрута
                  для учёта времени работы места.

                  Допустимые значения:
                  "круглосуточно"
                  "10:00-20:00"
                  "08:00-15:00"
                  или null, если достоверно определить часы работы нельзя.

                  Не записывать сюда длинные описания.

  benefits      — Дополнительные преимущества места или null.

------------------------------------------------------------
ID КАТЕГОРИЙ — ЗАФИКСИРОВАНЫ, МЕНЯТЬ НЕЛЬЗЯ
------------------------------------------------------------

  category_id: 1   ->   Достопримечательности
  category_id: 2   ->   Музеи
  category_id: 3   ->   Парки и прогулки
  category_id: 4   ->   Гастрономия
  category_id: 5   ->   Развлечения и активный отдых
  category_id: 6   ->   Религиозные объекты

Использовать можно ТОЛЬКО эти ID. Новые категории через импорт
создавать НЕ нужно.

------------------------------------------------------------
ПРАВИЛА ДЛЯ PRICE И IS_FREE
------------------------------------------------------------

Если место бесплатное:

  "price": "0",
  "is_free": true

Если место платное:

  "price": "500",
  "is_free": false

Значение is_free должно соответствовать price.

------------------------------------------------------------
ПРАВИЛА ДЛЯ OPENING_HOURS
------------------------------------------------------------

Поле opening_hours НЕ удалять.

Оно используется сервисом построения маршрута для проверки
доступности места в выбранное пользователем время.

Использовать только короткий нормализованный формат:

  "круглосуточно"

или:

  "10:00-20:00"

Если достоверных данных нет:

  "opening_hours": null

Не использовать:
  "working_hours"
  "rating_status"
  длинные текстовые описания часов работы.

------------------------------------------------------------
ПРАВИЛА ДЛЯ ФОТОГРАФИЙ
------------------------------------------------------------

photo_url должна быть строкой с прямой ссылкой на изображение
или null.

Предпочтительно использовать:
  - Wikimedia Commons;
  - официальные сайты;
  - туристические порталы города;
  - другие доступные в России источники.

Не использовать ссылку на страницу сайта вместо прямого URL
изображения.

------------------------------------------------------------
ВАЖНЫЕ ПРАВИЛА
------------------------------------------------------------

1. Не добавлять блок "categories".
2. Не создавать новые category_id.
3. Не добавлять дубликаты мест.
4. Не использовать working_hours.
5. Не использовать rating_status.
6. Не удалять opening_hours.
7. Не придумывать адрес, координаты, цену или часы работы.
8. Для каждого места указывать конкретный адрес.
9. Координаты должны соответствовать именно этому месту.
10. JSON должен быть валидным.
11. Использовать только двойные кавычки.
12. Кодировка файла — UTF-8.
13. После последнего элемента объекта или массива запятая не ставится.
14. city_id места должен соответствовать id города в блоке cities.
15. category_id должен быть от 1 до 6.
16. opening_hours должен быть коротким значением, диапазоном времени или null.
